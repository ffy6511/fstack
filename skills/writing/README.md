# 写作

改中文、写文档、做讲解页和口播视频时用。

| Skill | 用途 |
| --- | --- |
| [`writing-style`](writing-style/SKILL.md) | 查中文黑话和 `不是 X，而是 Y` 句式。词给替换，对比句看 X 值不值得留。写中文时默认就跑。 |
| [`humanizer-zh`](humanizer-zh/SKILL.md) | 去掉空话、重复和套话，保留事实和语气。上游是 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)，这里是 `f4518a8` 的拷贝。 |
| [`docs-substance`](docs-substance/SKILL.md) | 看文档写给谁、用词清不清楚、一条信息该放在哪一档。手动 `/docs-substance`。 |
| [`editorial-html-explainer`](editorial-html-explainer/SKILL.md) | 做单页长文 HTML（目录、图、代码）。手动 `/editorial-html-explainer`。 |
| [`code-walkthrough-site`](code-walkthrough-site/SKILL.md) | 做渐进代码讲解站：左边文章，右边 IDE，滚动到检查点再揭下一段代码。 |
| [`remotion-promo-video`](remotion-promo-video/SKILL.md) | 做口播宣传片：Remotion、本机 TTS、词级字幕。 |

`writing-style` 记笔记和写代码都会用到。它只放在这一组。别的项目要它时，再链这一个目录。
