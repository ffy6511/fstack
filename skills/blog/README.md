# 博客

写正文、特殊标记和配图时用。

| Skill | 用途 |
| --- | --- |
| [`note-prose`](note-prose/SKILL.md) | 正文放在哪一年哪一月、frontmatter，以及句子怎么接。 |
| [`note-writing-style`](note-writing-style/SKILL.md) | 中文的节奏、用词和作者自己的语气。改稿时和 `note-prose` 一起用。 |
| [`note-markup`](note-markup/SKILL.md) | 卡片、诗、文件夹、双链、公式和提示框。 |
| [`note-figure`](note-figure/SKILL.md) | 用 mermaid 或 Excalidraw 给讲解配图。 |
