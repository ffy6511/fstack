# @fstack/dsh-panel-entry

在 DSH 右侧栏用一个 **Panel** 入口管理回复摘录、Todo 和面板笔记。顶部显示当前工作区，下面三个分区切换；摘录数量和未完成 Todo 数量直接显示在分区名称旁。

按钮、搜索框、复选框、分段标签和图标复用 DSH 原生组件及其 CSS 类。面板布局和多行输入框使用宿主的字体、颜色、圆角与焦点样式变量，随 DSH 主题切换。

## 使用

### 回复摘录

在聊天中选中 agent 已完成回复的一段文字，浮层提供「引用文本」「加入摘录」「加入 Todo」。点击「加入摘录」后，右栏自动打开 Panel 的摘录分区。

- 摘录保存选中的可见文字，按保存时间从新到旧排列。同一条消息的相同片段重复保存时只保留一份。
- 每条摘录显示来源会话、轮次和保存日期，可以搜索摘录、个人笔记或来源会话。
- 「添加个人笔记」可为这条摘录补充想法，保存后显示在原文下方。支持编辑、取消；清空内容再保存可移除笔记。个人笔记与摘录一起保存在 `.dsh/panel.json`。
- 摘录底部操作合为一行：左侧是个人笔记和「转为 Todo」，右侧是「回到消息」「删除摘录」图标，悬停显示提示。
- 点击「回到消息」图标或来源名称，打开来源会话、加载对应历史，再滚动到原回复并短暂高亮。
- 「转为 Todo」保留摘录，同时新建一条带来源的待办，并切到 Todo 分区。
- 「删除摘录」图标移除摘录。已经生成的 Todo 保留内容和来源。

选区限定在同一条已完成的 agent 回复内；用户消息和思考内容继续提供原有引用功能。跨消息选区不提供摘录操作。

### Todo

Todo 默认显示未完成项。可以直接输入新待办，也可以从回复选区或已有摘录创建。

- 勾选完成，切到「已完成」后可取消勾选恢复。
- 支持编辑、删除、搜索，以及未完成 / 已完成 / 全部筛选。
- 从回复创建的待办保留「回到消息」入口。
- 手动添加的待办无需关联会话。

这里管理用户保存的工作区待办，DSH agent 自身的执行计划继续由宿主管理。

### 笔记

「笔记」分区直接内嵌现有 Markdown 文件面板，默认显示工作区根目录的 `NOTES.md`，可配合 [`panel-note`](../../dsh-skills/panel-note/SKILL.md) 使用。文件不存在时创建骨架，已有内容保留。

需要启用 `dsh-better-sidebar`，复用它注册到 DSH 原生右栏的文件编辑器。可在 Panel 内切换预览与编辑、保存、刷新，不另开标签页。切换到摘录、Todo 或其他右栏标签时，笔记编辑器保持挂载，保留编辑内容和位置。

## 存储

摘录和 Todo 按工作区保存在 `.dsh/panel.json`，以独立列表显示。保存摘录或待办时不会创建或追加 `NOTES.md`；首次进入「笔记」分区时才会确保笔记文件存在。

同一工作区的多个会话共用数据。每次修改先读取最新文件，顺序合并操作并原子替换；刷新面板、重新显示标签或窗口重新获得焦点时会重读文件。JSON 格式损坏或版本无法识别时会显示错误并保留原文件。

备份工作区时带上 `.dsh/panel.json` 即可保留摘录与待办。回到消息需要当前 DSH 中仍有来源会话；单独复制 JSON 可以查看已保存的文字。

## 安装

从仓库 checkout 装进 profile：

```bash
git clone https://github.com/ffy6511/fstack.git
dsh plugin --profile desktop add ./fstack/dsh-plugins/panel-entry-plugin
```

首次安装后，在 DSH 的「插件」页面确认插件已启用。更新本地源码后，可在插件详情中关闭再启用 `@fstack/dsh-panel-entry`，重新加载该插件的 host 与客户端。

当前 profile 支持热重载时，这样即可生效；若 DSH 提示需要重启，再完全退出并重开应用。页面刷新不会重新加载 host 代码。

## 使用条件

- 支持 DSH `0.2.2-rc.1` 版本线，使用原生选区浮层、右侧栏和主题组件。
- 需要会话关联可写的本机工作区目录。
- 消息定位依赖 DSH 的消息标识和聊天视图。来源会话已删除或归档后需先恢复；来源会话停留在其它视图时，切回「对话」后重试。
- 一个 DSH host 内的工作区修改按顺序保存。两个独立 DSH host 同时修改同一工作区的面板文件时，请避免交叉编辑。
