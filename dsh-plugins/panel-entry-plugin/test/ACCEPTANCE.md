# Panel acceptance

Date: 2026-11-11. Runtime: DSH 0.2.2-rc.1, macOS, Node 26.4.0.

- **Automated: passed.** `npm test` builds the client and runs 13 tests covering selection roles, native quoting, source navigation, cold-session loading, embedded editor identity/lifetime, HTTP mutations, persistence, concurrent updates, Todo actions, workspace isolation, and invalid-file preservation. Personal-note coverage includes per-clip persistence, edit/clear, deduplication, source/original-text preservation, invalid input, and deleted clips.
- **Package: passed.** `npm pack --dry-run` includes `index.js`, `client.js`, `src/store.js`, `cordis.patch.yml`, `package.json`, and `README.md`.
- **Temporary web profile: passed.** Installed with `DSH_HOME=<temporary-directory> dsh plugin --profile web add <plugin-directory>` and started with `DSH_HOME=<temporary-directory> dsh --profile web --no-open --port 18847`. Browser checks covered reply selection → saved clip, selection → Todo, clip → Todo, manual Todo entry, editing/completing/filtering, reload persistence, and native quote insertion. A second session opened a saved clip from the first turn of a 60-turn source session; the host loaded history and scrolled to the original reply seat. With Better Sidebar 0.30.1 in that temporary profile, the notes section embedded its existing editor: preview → edit → switch to Todo and back → save → preview, with only one Panel tab. Screenshots: `panel-entry-final.png` and `panel-entry-notes.png` in the task artifacts.
- **Running desktop profile: passed.** Disabled and re-enabled only `@fstack/dsh-panel-entry` in the native plugin manager. The component returned to running; the existing conversation displayed the new Panel sections and Todo controls. The final embedded-editor client was published by DSH's bundle hot reload: selecting Notes displayed the existing NOTES.md heading and its preview/edit/save controls inside Panel. Other plugin enablement states matched the pre-reload list. The desktop app and host processes remained running. Profile patch files and lockfile were unchanged; the plugin manager moved Panel to the end of the bundle list.
- **Personal notes and native styles: passed in a temporary web profile.** With a disposable workspace, browser checks covered adding a multiline note, cancelling an edit, editing, searching by note text, page-reload persistence, clearing, and adding again. Todo creation also passed with the native primary button. Runtime DOM inspection confirmed DSH's own button, input, checkbox, and segmented-control classes; the panel typography resolved from `--dsw-font-xs-13`. Screenshot: `panel-personal-note-native-styles.png` in the task artifacts.
- **Latest desktop host/client reload: passed.** Only Panel's bundle selection was removed and restored through the profile manifest watched by DSH HMR. Its HTTP route returned 404 after unload and 200 after reload; the desktop host accepted `clip.note` against disposable workspace data. The desktop client graph published revision `f19385c5d87e`, and its served bundle contained the personal-note action, native typography, and native link icon. The original manifest content and bundle order were restored; dependency selections, lockfile, and other plugin settings were preserved. Native desktop UI inspection of this final revision was not run because the desktop control connection timed out; its visual/interaction checks used the temporary web profile.
- **Compact excerpt actions: passed.** In a temporary web profile, both excerpts with and without personal notes displayed one action row: note/Todo actions on the left and two icon-only buttons on the right. At a 320px panel width, all four controls stayed on one row without overflow. Hovering the two icons displayed DSH's native “回到消息” and “删除摘录” tooltips; adding and saving a personal note still worked. The selection actions now share the same ghost-button variant. Screenshot: `panel-compact-actions.png`. Desktop client HMR published revision `a84170f2f389`; its served client matched the generated local bundle. This client-only update required no profile edits or host restart.
- **Formatting: scoped files passed.** Repository-wide `npx prettier --check .` reports 154 existing files outside this change. Those files were left untouched.

The temporary profile and browser space were removed after the checks. Native desktop selection saving was not run against user conversations; mutation flows were exercised in the temporary profile.
